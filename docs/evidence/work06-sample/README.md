# Work 06 Curated Evidence Sample

This small sample was generated by two independent `RapidClientConnection` instances running
simultaneously against the real `GameServer` with Java 26. The server used the disabled repository
adapter so that the sample could be produced without changing or imitating MySQL data.

- Session state before the burst: `PAUSED`
- Scenario: asynchronous `STEP_GAME`
- Requests: 20 from Client A and 20 from Client B
- Combined result: 40 sent, 40 responses, 40 success, 0 lost, 0 duplicate
- Client send windows overlap.
- Server maximum recorded queue depth: 28
- Server maximum recorded queue wait: 16 ms
- Every server evidence row reports a virtual session worker.

The full 200 + 200 evidence run should be generated on the demonstration laptop with MySQL and the
normal server configuration. Files under the runtime `test-results/` directory are intentionally
ignored by Git; this curated set is retained as a schema and behaviour example.
